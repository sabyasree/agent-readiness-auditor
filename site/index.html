Why another checker?

Most “agent-ready” tools check files. This one checks whether agents can get things done.

Agents read your page through its accessibility tree, the same structure screen readers use. A button with no name, a field with no label or a cookie banner in the way can stop them cold, no matter what’s in your robots.txt.

Typical agent-readiness scores

  • Does robots.txt exist?
  • Is there an llms.txt file?
  • Are MCP and OAuth discovery files published?

Features

Everything you need to make a page work for agents

New

Test a task the way an agent would

Type what a visitor would ask an agent to do, like “Add this backpack to the cart”. Chrome’s built-in AI reads your page exactly as agents do and plans the clicks, then the auditor shows each step on the page and where an agent would get stuck.

It runs on your computer with Gemini Nano: free, private, no API key. On computers without it, the test matches the task to control names.

New

Scan your whole site, fix the template once

Audit up to 25 pages from your sitemap or navigation in one go, free. The scan shows which problems repeat across pages, and a problem on most pages almost always comes from one shared template or component.

Copy one fix prompt for the shared problems, open a site report for your team or client, or download a CSV.

New

Know what to fix first, and see it all on the page

Fix these first picks the three changes worth the most points and shows the score you’d reach. Mark issues on page puts a numbered marker on every problem element at once; hover a number for details.

See your page the way an agent reads it

The Agent view shows the page as an agent reads it: its accessibility tree as text, with a token estimate. Buttons and links with no name are flagged in red, because to an agent they’re just “button”.

Select any line to find it on the page, filter to unnamed controls, or copy the whole snapshot.

New

Ready for AI shopping agents?

On product pages, the auditor checks what shopping agents rely on: Product structured data, price and stock (and whether the price matches the page), shipping, returns and ratings, and an “Add to cart” that’s a real, clearly named button.

Hand the fixes to your coding agent, or to your client

Every problem element comes with suggested code you can copy: a real button instead of a clickable div, a label for a field, a name for an icon button guessed from the page. Or copy the whole report, the top fixes, or a single issue as a ready-made task for Claude Code, Cursor or Copilot. It tells the agent to fix each issue at its source, write a test, verify it and keep going until the checklist is done.

Share report makes a clean, standalone report you can send to a client or save as PDF.

What it checks

42 checks in ten areas

Each area gets a score, weighted into one overall score from 0 to 100. Checks that don’t apply to the page are left out rather than counted against you.

20%

Real controls

Clickable divs that aren’t real buttons, links that go nowhere, controls the Tab key skips, no visible focus.

20%

Labels and names

Icon-only buttons, vague names like “Click here”, missing alt text, misleading ARIA.

15%

Forms

Unlabeled fields, missing input types and autocomplete hints, unmarked required fields.

15%

Interaction traps

Cookie banners and overlays, CAPTCHAs, cross-origin frames, tiny targets, layout shifts. Shadow DOM and same-site frames are checked too.

12%

Stable targeting

Controls only reachable by generated class names or auto-generated IDs.

12%

Page structure

Title, language, landmarks, headings, page size, content that needs JavaScript.

10%

Shopping agents

Only on product pages: Product data, price and stock, shipping, returns, ratings, a clear Add to cart.

6%

Agent safety

Hidden text that reads like instructions to an AI agent.

6%

Machine-readable signals

Meta description, Open Graph, structured data, llms.txt, robots.txt rules for AI.

FAQ

Questions

Which agents does this help with?

Any agent that reads web pages through the accessibility tree or the DOM, including Claude in Chrome, Gemini in Chrome, ChatGPT agent, Perplexity Comet and agents built on Playwright or browser-use. Agents that work from screenshots benefit too: real buttons, clear names and stable layouts help them as well.

Isn’t this just an accessibility checker?

There’s a lot of overlap, because agents and screen readers read the same structure. But it also checks things accessibility tools don’t: hidden prompt injections, content that only appears after JavaScript runs, selectors that break on every release, how many tokens come before your main content, and agent protocols like MCP and WebMCP.

Do I need llms.txt or an MCP server to score well?

No. Protocol files are shown for information and don’t affect the score. Few sites publish them and few agents read them yet. Whether an agent can actually use your page matters far more.

Does the Agent test send my page to an AI service?

No. It uses Chrome’s built-in model, Gemini Nano, which runs on your computer. Chrome downloads it once, on the first test, if your computer meets Chrome’s requirements. Without it, the test matches your task to control names inside the extension. Nothing leaves your browser either way.

Can it check my whole site?

Yes, up to 25 pages at a time, for free. Open the Site scan tab, choose pages from your sitemap or your navigation, and the extension audits them one by one in a background tab. It asks for access to that one site only.

Can I run it in CI or from a coding agent?

Yes. The same checks are available as a command line tool: npx agent-readiness-audit http://localhost:3000 --min-score 80 fails the build when the score drops below 80. Run npx agent-readiness-audit mcp as an MCP server and coding agents like Claude Code or Cursor can audit a page, fix it and audit again on their own.

Which languages does it support?

The extension follows your Chrome language: English, Spanish, German, Japanese, Portuguese (Brazil) and Bengali. Exported reports and prompts for coding agents stay in English.

Does it cost anything?

No. The extension is free, with no account and no usage limits.

How accurate is the score?

The checks are heuristics: they find likely problems fast and point to the exact elements. Use the score to find and prioritize fixes, then confirm with a real agent run on your most important flows.
