Can an AI agent actually use your website? Agent-Readiness Auditor checks how well agents like Claude, Gemini, ChatGPT agent and Perplexity Comet can read a web page and complete tasks on it, then shows you exactly what to fix, starting with the fixes worth the most points.

Open any page and click the icon. The audit starts right away, and in about a second you get a 0–100 score, a breakdown by category, and every problem element with why it matters and how to fix it. The score also appears on the toolbar icon.

Most "agent-ready" checkers only look for files like robots.txt and llms.txt. This one checks whether an agent can find your controls by name, fill in your forms, get past overlays, buy from your product pages and read your content without being misled.

WHAT IT CHECKS (42 checks)

• Real controls: clickable divs and spans that aren't real buttons or links, links that go nowhere, controls the Tab key skips, no visible focus, positive tabindex
• Labels and names: icon-only buttons with no label, vague names like "Click here", images without alt text, misleading ARIA
• Forms: unlabeled or placeholder-only fields, missing input types and autocomplete hints, required fields not marked as required
• Interaction traps: cookie banners and overlays, unnamed dialogs, CAPTCHAs, cross-origin frames, shadow DOM and same-site frames, tiny click targets, layout shifts
• Stable targeting: controls that can only be found by generated class names or auto-generated IDs
• Page structure: title, language, landmarks, headings, page size, content that needs JavaScript, where the main content starts
• Shopping agents (product pages): Product data, price and availability, shipping, returns, ratings, the cart button
• Agent safety: hidden instructions aimed at AI agents
• Machine-readable signals: meta description, Open Graph, canonical link, structured data, llms.txt, robots.txt rules for AI
• Agent protocols (for information, not scored): Markdown for agents, sitemap, MCP server card, API and OAuth discovery, Content Signals, WebMCP

WHO IT'S FOR

Front-end developers, QA and accessibility teams, SEO and GEO specialists, e-commerce teams, and agencies preparing sites for AI agents and agentic browsers. Agencies: scan a client's site, compare it with competitors, and send the report.

PRIVATE BY DESIGN

Audits run entirely in your browser. No account, no servers, no analytics, no tracking. Nothing about the page is sent anywhere, and the Agent test's AI runs on your own computer. The extension only reads a page when you click its icon, and asks for access to a site only when you start a site scan or turn on re-run on reload. Weekly re-scans run in the background only for the sites you turn them on for, and alerts only appear if you allow notifications.
